Linux prerequisites

Requirements for the Linux 1.0.0b2 test package.

Linux test buildThese requirements describe the included runtime bundle. Recorded native checks include Pop!_OS 22.04; the focused DOS-door caller checks also passed on Linux Mint 22.3. This is not qualification of every browser, Linux version or BBS feature. Matching the library versions below does not by itself qualify a system.

Computer and runtime software

Use native AMD64 / x86-64 Linux with glibc. This package is not qualified for ARM, 32-bit systems, macOS / Darwin or Alpine / musl. WSL1 is used for builds and core checks, not as a fully qualified BBS host.

You need Python 3.8 or newer for the installer and entry scripts, plus glibc, libstdc++ and libgcc runtime libraries. The full bundle, including ClamAV, needs glibc 2.30 or newer and a GCC 9-era libstdc++ runtime. Its required C++ symbol versions are GLIBCXX_3.4.26 and CXXABI_1.3.11.

No compiler, CMake or Rust SDK is needed to run this ready-built package. BBS SSH uses built-in DeuceSSH; you do not need a separate OpenSSH BBS server. SFX does not reconfigure the operating system's administrator SSH service.

Desktop and browser controls

The normal first-run path uses a terminal on the Linux desktop, then a default browser opened by xdg-open (usually from xdg-utils). No separate Qt or GTK toolkit is needed. After installation, run its exact printed spitfire-x command to open the Control Panel, complete initial BBS setup, review settings and choose Start BBS deliberately.

Pop!_OS 22.04 and Mint 22.3 have been used for native SFX testing at the recorded scopes. The release notes identify this candidate's actual fresh-install, upgrade and runtime checks. Other glibc x86-64 distributions meeting the listed requirements are expected to be portable, not universally qualified. Building SFX yourself remains an option; bundled vendor assets keep their separate runtime requirements.

For a connection from another computer, follow the complete SSH forwarding instructions. The --print-url option prints a private, expiring loopback link; it needs that same-port SSH forward to reach it from a remote browser. LAN HTTPS/Web Access is a separate post-setup choice.

Your account, folder and startup

A fresh Linux board uses a new, empty folder with the lowercase layout. An existing lowercase board can use the same-folder upgrade, preserving its board data and settings. Older uppercase boards and archives are not converted. See layout names and exceptions.

Install and run SFX as your normal Linux account, not root. Use the default ~/sfx or another folder you own. A new board starts with callers stopped. The default caller ports are Telnet 2323 and SSH 2222; the optional low-port service plan still runs SFX under your normal account.

Starting management with Linux and Start BBS when Linux starts are separate choices. Follow Linux browser controls for installation, setup, service plans, updates and recovery.

Included extras and network access

Portable ClamAV 1.4.7 is included. It needs Internet access for initial virus definitions and updates; engine files alone are not ready definitions. Check the result on the ClamAV page. If a required scan cannot finish, SFX does not publish the upload. An already received file can remain held privately for Sysop review.

Fresh installations add SFX Guess a Number, NewsWire-X RSS and the native X-Gate gateway menu entry. Updates preserve your Door and menu choices. Original DOS games and DOSEMU2 are not installed by this package. Optional DOS Doors may need an emulator or other software; check each Door's requirements in Doors.

RSS feeds, FTN and public gateways need their own working network access. The Wiki works offline.

Allow room for your board

Keep room for programs, virus definitions, board data, uploaded files and verified backups. Final download size and minimum disk or memory figures are not fixed yet. Source companions are separate downloads, not source folders installed with the BBS.
