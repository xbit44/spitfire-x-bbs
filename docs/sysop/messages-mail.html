Messages and offline mail

Guide callers through reading and scans, set up public message areas, and manage local and offline mail.

Use Messages > Groups & Local Echoes for the local message catalog. An echo is a public message area. A group gathers related echoes under one heading; the group's access requirement applies as well as each echo's requirements. Network connections and imported echo tags are covered under FTN networks.

Caller Message Menu

From Main, choose M Message Menu. The commands below describe caller reading and scans. A conference is a public message area; its access and reading permissions still apply. Private mail remains limited to its authorized participants. A command for reading messages does not send a new message.

Use ? for help on the commands currently offered. Follow the prompt for the current screen: Q in a reader, QWK or Scan Settings has that screen's return behavior, rather than being a universal logoff key. Entered message or editor text is not a navigation command.

R Read Messages

The Read menu offers T This Message Conference, A All Message Conferences, O Only Queued Conferences, N New Message Scan and Q Return to Message Menu. Your Message Scan is the direct Y command on Message Menu.

This Conference

T identifies the selected accessible conference by number and full group/conference name, shows its available message-number range and your saved reading position, and offers a message number, L List or Q Quit. If the saved message is still available, Enter resumes that message itself. Opening an older message does not lower your saved highest reading position.

Without a usable saved message, choose an available number or List; SFX does not silently jump to the newest message. Empty, removed or inaccessible areas get an appropriate notice. A failed read is not reported as an empty conference.

All and Only Queued

A reads accessible conferences in configured order. O uses conferences where Unread OR To-you is enabled in Scan Settings; it selects conferences, rather than meaning unread message bodies only. Each conference keeps its own saved position and T-style number/range/resume/List starting prompt.

K Skip Conference leaves the rest of that conference and advances to the next eligible one. At a long-body paging pause, S Stop stops displaying that body and reaches its reader controls; it does not skip the conference. Q ends the whole All/Queued run and returns to Message Menu. Empty conferences show a brief notice and advance; no eligible conferences or the end of the last one returns to Message Menu without wrapping.

All/Queued does not replace your separately saved Change Conference choice. Skip or Quit does not catch up unread positions or mark skipped mail received; ordinary effects from a body already opened remain subject to the current Preview choice.

New Message Scan

N retains the existing new-message scan and its current-echo, current-group or all-accessible scope. It uses the shared Unread/To-you selections. It is separate from Your Message Scan and the private Inbox/Sent views.

Y Your Message Scan

Y opens your personal-message summary and review directly from Message Menu. Reading defaults to T To You; choose F From You, B Both, L List or Quit as offered. The List filter defaults to B Both and offers T To You, F From You, I Private Inbox, S Sent Private/NetMail and Q Quit. Q here returns directly to the Message Menu. Lists use the numbered To/From/Subject/Date layout below. Opening a sent copy does not mark a recipient's copy received.

If an existing Y Door shortcut is available to you, SFX first offers Y Your Message Scan, D for that Door or Q Return. Enter defaults to Your Message Scan. This choice keeps the configured Door reachable rather than silently replacing it; D is the choice inside this conflict prompt.

The personal scan retains its saved public To-you scan eligibility and access checks, together with your received private mail. It is not an unread-only login count. Use the offered filters to distinguish personal public matches, received private mail and sent-private history. Selecting a filter does not grant access to another caller's mail.

Listing headers alone changes neither saved reading positions nor received status. Opening a body uses normal reading or the configured System Sysop's Preview choice. Reply, quoting, editing, Save and Abort retain their existing behavior and return to the opening reading/list context.

Lists and B Browse Messages

Browse offers T This Conference, A All, O Queued and Q Quit, with This Conference as the default. All/Queued shows one conference at a time in configured order, skipping empty conferences and preserving your separately saved current-conference choice.

Each list shows selection number, To, From, Subject and Date. A displayed selection number chooses that row; it is distinct from the actual conference-local message number shown in the selected details. Selection numbers continue through the pages of a conference, and messages retain their normal message-number order.

Use Up or Down to move the lightbar one result at a time. Up from the first visible row selects the last row of the previous page. Down from the last visible row selects the first row of the next page, even when that page is only partly full. The lightbar stops at the first and last results. PgUp/PgDn still move a full page. Press Enter to open the selected row, or type its displayed number and press Enter in the numbered view. The conference heading follows the displayed list.

To/From/Subject text is shortened inside its own column, with a gap before the next field. An ellipsis describes display truncation only; the stored subject, names and message body are not shortened.

After a Browse body finishes, Enter or L returns to the same list page and selection. At a paging pause, Enter still continues that body. Explicit Next/Previous, Reply, scrolling and authorized actions remain available. K skips current-conference results in All/Queued; Q/Escape at Browse navigation prompts returns to Message Menu. S remains paging Stop.

Delete or restore a listed message

In a header list, highlight the row and press D when [D] Delete is offered. In the plain numbered view, enter D 12 to act on displayed row 12. The change saves immediately and a * appears beside the row number. To restore that row, press D again when [D] Undelete is offered. You can use the same numbered command to restore it. The star clears when the restore succeeds.

These controls apply to the starting Read list, Your Message Scan, Browse, Search and Specific Caller lists. Each action checks current permissions and Permanent protection. A deleted row stays available only to callers who can restore it. Removing a message from your Private Inbox affects your recipient copy. Deleting a message for everyone requires the separate authority for that action.

List paging, deleting and restoring a row leave the read or received status and saved reading position intact. Opening the body uses normal reading or System Sysop Preview.

T Search Messages

Choose This Conference, All, Queued or Quit; This Conference is the default. Enter a literal word or phrase of up to 128 characters. Matching retains the existing case handling and checks Subject or body. It is not a Boolean, wildcard, regular-expression or six-keyword search.

Results use the Browse-style layout, lightbar or numbers, PgUp/PgDn, selected details and display-only truncation. After a body, Enter/L returns to the same result page and selection. Explicit Next/Previous visits matching messages only. K skips a conference's matches in All/Queued; Q/Escape at search navigation returns to Message Menu; S remains paging Stop.

Watch progress and the matching-message total. Completed no matches, cancellation/partial results and a failed search are different outcomes. The saved current conference, message access and normal/Preview read-state rules remain in effect.

S Specific Caller Messages

Choose This Conference, All, Queued or Quit, default This Conference. Choose L Local caller or H FTN/header name, enter a full or partial name, choose the complete candidate and confirm it. Known local identity, network and address distinguish similarly named participants; a remote sender need not have a local account.

Choose To, From, Both or Quit. Both is the default, and a message matching both directions appears once. This searches readable public conferences; use Your Message Scan's retained private-mail views for your Inbox and sent-private copies.

Matching results keep the Browse layout, paging, numeric/plain fallback and same-page/selection return after body Enter/L. Explicit Next/Previous stays among matching messages. K skips a conference's matches in All/Queued, S stops body paging, and Q/Escape at navigation returns to Message Menu. With no candidate, choose retry or Quit; distinguish a completed no-match result from a cancelled or failed operation. Existing access and Preview/read-state rules still apply.

A Caller Message Scan Settings

From Message Menu or QWK, open Message Scan Settings, choose a group and review its conferences. Unread includes new public conference posts in regular new scans. To-you includes messages addressed to you in personal/new scans. The two columns are independent. If no preference is saved, both start On; an update keeps saved choices. O Queued includes an accessible conference when either flag is On.

Use arrows/PgUp/PgDn to navigate, Left/Right to choose a column and Enter to toggle it; follow the matching plain/narrow controls when a lightbar is unavailable. Each individual toggle saves immediately. Check its saved or failed result before assuming the new value is in use.

For a group-wide column change, review the group, selected column, intended On/Off value and affected count. Confirmation defaults to No. These changes keep reading positions, received status, private-mail settings and your current-conference selection. Turning off a scan flag does not remove separately authorized manual reading or posting access.

Q/Escape backs to the group list and then to the opening Message or QWK menu. QWK uses the same saved public-echo selections, with its separate received-private inclusion controlled by Packet Settings; it does not maintain a second subscription list.

C Change Conference

Choose a message group, then a numbered accessible conference. Cancelling before a valid change keeps the old selection. After a successful save, SFX asks whether to read the selected conference now, with Yes as the default.

Yes enters that conference through T's reading flow directly, without another Read scope menu: applicable Preview, saved position/range, message number, Enter to resume and L List. No or cancellation at the read-now question returns to Message Menu while keeping the newly saved conference. A failed save is reported as a failure, not a successful change. Leaving the reader returns to Message Menu with the new conference retained.

System Sysop Preview and read state

Only the board's configured System Sysop account is offered Preview, default No, once before the first body in a reading visit. Sysop security privileges alone do not offer it to another account. A new reading visit starts at No rather than saving a caller preference or inheriting an old visit.

No gives normal reading effects. Yes permits authorized body reading without changing the original message's received status or your saved last-read position. The choice carries across that visit's reading/list body opens. Header listings alone change neither state in either mode. Preview never expands access to private or otherwise unavailable mail.

Replies save normally even during Preview. The original message's state remains protected, and the normal reply target/network, quoting/editor, Save/Abort and opening reading/list context remain unchanged. Enter Message and QWK/REP retain their current functions; Preview is not a new packet, reply or private-mail permission.

Groups and local echoes

Linux SFXConfig: Choose a named group or echo and use its actions below the list. Browsing another row can change the available actions while the current Editing item remains open. Save Changes saves that Editing item; use the intended Edit action before changing a different item. See editing and save results.

A fresh installation has an enabled Local group, access level 1, containing Sysop Notices and Public Chat. Both echoes allow access and reading from level 1. Sysop Notices initially requires the configured Sysop threshold for posting; Public Chat allows posting from level 1. Updates preserve your saved catalog and settings.

On Windows, enter Unlimited for an unlimited retention limit. On Linux, leave the corresponding field blank. Zero is not a finite limit. For example, count 5000 and age 90 permit retention to remove messages that exceed either limit.

Choose New Group or New Local Echo, enter the fields and review Save. For a new echo, select its parent group first. Use the next-page controls when the catalog has more entries. Save applies the current access rules without a BBS restart. Moving an echo preserves its messages and stable identity. Saving retention values removes nothing immediately.

The catalog assigns a conference number from 1–999; you do not type a new number when editing an echo. Caller-visible numbers follow readable group order. Use Insert to place a new echo before a selected echo, or Up/Down to change order. Select by name and review the current entry rather than relying on an old screen position.

If another edit changes the catalog, reload and review the new values. If Save has an unresolved outcome, use Reconcile for that same operation before making another change. A missing response is not proof that Save failed.

Clone Options

Linux SFXConfig: Choose the source echo and exact targets through the named lists. Check the selected fields and before/after review before applying the copy. Choosing another browse row alone does not replace the open clone draft. See editing and save results.

Clone Options copies selected settings from one echo to explicitly selected target echoes. It does not create copies of the messages or the source echo.

  1. On Windows, select the source in Groups & Local Echoes and choose Use as Clone Source. On Linux, open Clone Options, browse to the echo and choose Use as Source.
  2. Browse target groups and pages. Add the exact target echoes; the source cannot also be a target. Up to 999 distinct targets are accepted.
  3. Check only the fields to copy: Access, Reading, Posting, Maximum Message Count and/or Maximum Message Age. These choices start unchecked.
  4. Review the source, targets and before/after values, then apply the change. Clear targets before choosing a different source on Linux.

Unselected values stay as they were. Names, enabled state, pipe colors, message contents, Permanent flags, private-mail policy, numbers and caller scan state are not copied. With no fields or no targets selected, nothing changes. Permissions apply immediately; copied retention limits take effect at the next retention run. Apply does not purge messages or require a restart. If the source or targets changed since selection, discard the stale preview and select them again.

Retention and unread private mail

Public echo retention protects messages marked Permanent and messages with outstanding FTN work. They can keep an echo above its configured count; the job reports protected overage. Lowering a limit does not remove this protection. Count and age limits are independent, so Unlimited age still leaves a finite count limit in force.

Tools > Scheduled Jobs > Unread-Mail Age controls the recipient's unread private inbox. The fresh value is 365 full days; saved values survive updates. Acceptable values are 1–65,535 days or Unlimited. Enter Unlimited on Windows; leave the field blank in Linux's Unread Private Inbox Age section.

Use Save Unread-Mail Age on Windows or the section's Save Setting on Linux. This is a separate save from the job schedule. The next retention run expires eligible unread recipient-inbox entries. Read mail, sender copies and stored bodies remain. Save itself expires nothing and does not require a restart.

Review the actual job result under maintenance and recovery. A partial or interrupted job can have committed earlier batches; it is not equivalent to no change. A clean integrity check clears applicable integrity holds but does not itself run retention.

Remove an echo or group

Use Disable when you want to hide an area while retaining its messages. Delete Echo and Delete Group permanently remove the selected area and its public messages, including Permanent messages. Group deletion includes its contained echoes. Stop the BBS normally before using deletion.

The workflow first identifies the exact area and offers a backup. Choosing a backup requires it to complete and verify successfully; a failed backup stops that deletion attempt. Choosing no backup still leads to a separate final review. Check the name, echo count, message count and Permanent-message count before confirming. Cancel preserves the area; an already completed backup remains available.

If the result is unconfirmed, reconcile that exact operation and inspect the current catalog. Do not select a different area and repeat the command. Recovery requires a supported backup restore. Area deletion does not delete unrelated private mail, accounts or other groups.

For example, raising a level from 200 to 500 lines permits longer new messages but does not change its daily connection time.

Message pipe colors

In Windows SFXConfig, open General > Displays & Menus. Under Message Pipe Colors, choose Synchronet (default) or Legacy SFX and click Save. The private mail and NetMail switch is available in the same section and asks you to confirm a change separately. On Linux, the Use legacy message pipe colors checkbox selects the style. Echo and private-message settings control where pipe colors are enabled.

With pipe colors enabled, Synchronet style interprets |00 through |23. Pipe styling resets at each newline in the stored message and continues across lines that only wrap on screen. |24 through |31 appear as text.

Legacy SFX interprets all 32 codes and lets pipe styling carry across stored newlines. These choices affect display of plain-text message bodies. SFX keeps the stored text, authored ANSI artwork and FTN mail formatting as written.

Caller quote selection

The quote selector shows Space marks; A All; N ranges; ESC cancels; Enter returns.

Use Space to mark lines, A for all lines, or N to enter line numbers/ranges. Enter applies the current or marked quote lines and returns to message composition. Esc cancels the quote selection and returns to composition.

Open General > Board Identity for the separate QWK settings.

Use Save QWK; changing the board name does not save the QWK fields. Existing saved QWK values survive updates. Future packets use the new values without a restart. Changing the QWK ID makes older QWK/REP packets for the previous ID incompatible, while stored messages and conference mappings remain unchanged. Choose a stable ID such as NVALLEY before callers begin exchanging packets.

If the outcome is unknown, Reconcile QWK checks the same Save before allowing another change. A revision conflict means you should reload and review the current policy.

Callers download messages in a QWK packet and upload replies in a REP packet. While preparing a packet, SFX shows each selected message area as it scans, followed by Packing your QWK packet... before transfer.

While SFX prepares and packs the packet, a moving ##### line shows that it is working. This is an activity indicator, not a percentage or an estimate of time remaining. The line clears before the next prompt or file transfer.

Classic CP437 QWK packets use byte 0xE3 as a line-break marker. If that byte appears as the pi character (π) in a message body, SFX substitutes * in the downloaded classic packet and continues. The stored message and its real line breaks stay unchanged.

For a reader that supports UTF-8, choose Full headers: Yes and Encoding: UTF-8 in the caller's Packet Settings to keep that character in the packet. Read Packet choice saved. after changing a choice, then return to the QWK menu and choose D to download.

NetMail

For newly composed REP NetMail without an explicit domain or known reply network, SFX chooses one eligible route: first a zone-and-net match, then a zone match, then the first configured eligible fallback. There is no network prompt and the message is not sent through several networks.

An explicit domain or the network of a known reply is retained.
