Compact the stopped shared database?
A new successfully verified backup is mandatory first. Failure refuses compaction. Saved backup destination and retention apply. All logical contents and IDs must remain; size need not shrink.
The BBS must already be stopped. Closing this browser does not cancel the operation. Use Refresh Compaction Status to check the result; do not repeat an uncertain request.


Review the unconfirmed compaction request
The latest status shows no active compaction and no new result for your request. This does not prove that the request never reached the BBS.
Check the backup folder, preserved work and logs before finishing this review. Finishing only clears this browser's warning; it does not cancel, repeat or mark the earlier request successful. A later result may still appear.


Run this job now?
The BBS will not be started. This uses saved settings and existing protection. It is one request; an uncertain result must be checked in job history before another run.


Clear this temporary login delay?
The action is logged. Password checks, connection limits and other login delays stay in place. A short wait already in progress may finish normally. More failed logins can start another delay. BotGate IP bans are not cleared.


Replace permanent System Password?
Active Sysop sessions will be disconnected; ordinary callers remain. This is a permanent replacement, not a temporary reset. The old value cannot be recovered.
