# Control Panel application

Alpha 0.0.1 Slice B provides the real native Win32 Desktop Mode Control Panel. It launches and owns the sibling `SFXRuntime.exe`, performs protected first-run setup, and displays runtime-owned node, listener, terminal, log, and SQLite statistics state.

The cohesive Dark Retro interface includes a charcoal workspace and tab rail with warm-gold hierarchy, compact fixed-width operational typography, and restrained semantic state colors. It provides Nodes, Events, Live Logs, and Statistics; multiple read-only 80x25 CP437/ANSI Node Views whose visible per-tab `X` closes only that view; the idle banner and screen saver; persisted node enablement and UI preferences; the optional System Monitor; staged listener Settings with orderly Runtime restart and last-working-endpoint restoration; and confirmed Control Panel shutdown. Primary tabs are not closable, and real caller snapshots retain their original ANSI/CP437 colors.

Stage 4 uses matched private protocol 3.0 for all configured nodes (1–4, default four), with validated Runtime epochs, assignment generations and screen ownership. Indicators and Node Views are independent. Confirmation follows the selected node/view; disabling it does not stop other callers or either shared listener. Clearing presentation caches reconstructs from fresh authenticated status without interrupting callers, but actual owner exit or control-connection loss still shuts Runtime down. No ownership handoff or replacement-owner survival is implemented. Unimplemented BBS events/statistics remain unavailable; no scheduler, RLogin, Bot-Gate, FTN, message, file, transfer, Door, Chat, Service or installer capability is added. Stage 5 and owner-test packaging require separate approval.

Test-only fixture and bitmap-capture switches exist only when both `BUILD_TESTING=ON` and `SFX_ALPHA_TEST_AUTOMATION=ON`; normal Release binaries reject command-line options and contain none of those fixtures or switches.
