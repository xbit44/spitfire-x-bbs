# Production Source

The owner-authorized Stage 1-4 foundation establishes the production core/application dependency direction and reserves adapter, platform, and application directories for later approved slices.

Do not extend the foundation into networking, IPC, databases, UI, authentication storage, transfers, Doors, Chat, FTN, external helpers, runtime hosts, or Linux-native features without separate owner authorization.

Every later caller-facing or Sysop-facing feature slice must identify its OGSF behavior evidence, approved deviations, unresolved questions, behavioral conformance tests, and security tests.
